# Plintoo launch site: requirements for the first weeks

| | |
|---|---|
| Status | Draft 0.1, written 2026-10-13 after the launch panel and council of 2026-10-11 |
| Scope | One page. Early-cohort sign-up. No pricing page, no docs, no login. |
| Full site | `PRD.md` in this repo covers everything after launch. |

## Purpose

Make a director of a 5 to 50 person architecture practice want to be in the first cohort. One page, one action: Apply.

## Positioning (Ralf's choice, 2026-10-11)

Too many tools. One command centre. Plintoo runs the tools the practice already pays for, from one line, with any model behind it, and keeps every reason.

Conditions that stand whatever the wording:
- No "your tools don't talk" line. The vendors are fixing that.
- Nothing on the page that the build cannot do on video.
- Never branded as LibreChat.

## Register

Maritime.sh: headline is a verb phrase of five words or fewer; subhead is one concrete sentence; features are three words plus a number; the product is shown as a live screen, not described; buttons name the action.

## The council's rule (2026-10-11)

The page is written from the recording, not from the positioning. Film one thing the build does end to end, under one minute, first. If it drives two tools, the page says two tools.

## Screens, in order

1. **Hero.** Live mock of one typed line driving the apps behind it.
   Headline: "Run every tool from one line."
   Subhead: "Give your practice one command centre. [tools that run today]. Any model behind it."
   Buttons: Start free · Book a demo.
2. **Logo bar.** Only the tools that run today.
3. **Demo.** The recording. One line typed, the apps answer. Caption is the exact instruction used in the recording.
4. **Three capabilities.** Any model (swap in one click). Its own memory (held by the practice). Every reason kept (each action filed as a decision: why, evidence, who).
5. **Numbers.** [n] tools connected. [n] s from instruction to result. [£n] per seat per month and [£n] per seat per year.
6. **Three ways to run it.** Hosted (we run it, you log in). Your machine (one Docker command, data stays in the office) [only if offered]. Built for you (your workflow, your tools, a head start).
7. **Setup, three steps.** Connect. Ask. Keep.
8. **Who it is for.** Practices of 5 to 50 who will never run their own AI infrastructure and should not put project files into consumer chat.
9. **Early cohort.** "First [n] practices. Set up by hand." Fields: practice name, size, the tool you most want to stop opening. Button: Apply. Under it: what the first cohort gets, in one sentence, from what runs today.
10. **Footer.** Product · Pricing · Docs · Security · Company · Legal (links can be dead at launch; the page must not).

## Motion and media (after the spine is agreed)

Hero: tool icons sliding in until the screen is full, one typed line clears them. Section 2: parallax of tools stacking by year. Demo: the recording, autoplay muted, with the typed line shown as text. Everything else static. No stock, no renders, no AI-hype imagery.
